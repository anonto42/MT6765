# Caveman Format

Compressed state for continuation and review. Short lines, no prose, no secrets.

```
STATE: <one line: what works, what is broken, where the device is>
TODAY: <done today, newest first, one item per line>
NEXT: <ordered next steps>
HANDOFFS: <running/finished agents: branch -> status>
RISKS: <what can break the device or the build>
LOAD: <files the next session should read first>
```

Review answers in this style unless the user asks for normal prose.
