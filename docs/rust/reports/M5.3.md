# M5.3 X11 presenter, gestures, window properties, resize, /run/walpad-ok
Status: done on the host (against a real Xvfb); the Rust shell is not selectable on the tablet yet
Files changed: crates/walpad-x/* (new), crates/walpad-core/src/xbridge.rs (uses walpad-x), crates/walpad-shell/{Cargo.toml,src/*,tests/x.rs}, crates/walpad-ui/src/text.rs (WALPAD_FONTS), scripts/dev/host_session.sh, Cargo.toml
What works now:
 - walpad-x: the deadline-bound X stream/connection (every wait <= 2 s) extracted from the core's bridge so core and shell share it; core tests unchanged and passing.
 - Gesture recogniser (pure, fake clock): Pressed on down, tap = release within 10 px and 500 ms, long press fires once at 500 ms held within 10 px (also if the timer tick was late), drag beyond 10 px emits Cancel + DragStart + Drag{dx,dy} deltas + DragEnd, a lost Up restarts cleanly. 7 tests incl. the exact 10 px / 500 ms boundaries.
 - Presenter: premultiplied RGBA -> BGRX PutImage in row chunks (<= 256 KiB and <= the server's maximum request length), damage-rect capable, no MIT-SHM.
 - Window: WM_CLASS walpad-shell / WalPad-Shell, title "WalPad Home" (WM_NAME and _NET_WM_NAME), pointer, key and resize events; initial size from /run/walpad/orientation; ConfigureNotify (rotation / window manager) re-creates the frame buffer and re-lays-out.
 - Event loop: redraws only when something changed, waits on the X socket with a timeout bounded by the long-press deadline; writes /run/walpad-ok only after the first frame is presented; exits non-zero if the X connection dies (the supervisor restarts it).
 - Skeleton App: status bar, bottom navigation, tap switches tab (the real screens are M5.4-M5.7).
Checks run: scripts/check.sh -> ALL CHECKS PASSED. tests/x.rs against a real Xvfb: window class and title, first frame pixels (BGRX read back with GetImage), /run/walpad-ok appears, a real XTEST click on Network switches the active tab, resizing to 1280x800 re-lays-out and a click lands on the new layout. host_session.sh: shell frame captured (looked at it).
