What works now:
 - tokens: every colour from docs/rust/UI.md as constants (a test pins the hex values), spacing scale, radii, touch minimums, row/button heights, frame layout (status bar 40, nav 88, content ends at y 1192), type sizes, interaction thresholds.
 - Canvas on a tiny-skia pixmap: rect, anti-aliased rounded rect, rounded rect with 1 px border (the only elevation cue), circle, blit/crop for off-screen scroll areas and sheets, pixel read-back, PNG encode/save.
 - Text: DejaVu Sans / Bold / ExtraLight / Mono through fontdue with a glyph cache keyed by (face, char, size), measure, ellipsis fitting, left/centre/right and vertical centring in a box. Fonts load from a directory (/usr/share/fonts/dejavu on the tablet, falling back to the vendored copy).
 - 26 vector icons on a 24 px grid with 2 px round strokes drawn in code (no image assets); names map to apps.json `icon` ids.
 - Snapshot harness: assert_snapshot against tests/golden/*.png, UPDATE_SNAPSHOTS=1 regenerates and prints the changed names, tolerance = per-channel <= 2 and <= 0.1% of pixels. Three goldens (tokens+shapes, type roles, icon sheet) were generated and inspected by eye.
