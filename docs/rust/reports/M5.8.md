# M5.8 System dock (D3 = yes)
Status: done on the host (unit tests, 4 goldens inspected by eye, full-stack test against a real Xvfb); not yet on the tablet and not tried under openbox
Files changed: crates/walpad-shell/src/{dock (new),shell,lib}.rs, crates/walpad-shell/tests/{dock_snapshots (new),x}.rs, crates/walpad-shell/tests/golden/dock_* (4 new)
What works now:
 - `walpad-dock`: a separate small X window (WM_CLASS `walpad-dock`/`WalPad-Dock`, `_NET_WM_WINDOW_TYPE_DOCK`, WM_HINTS input=false so it never takes the focus) on its own X connection, owned by the shell and polled in the shell loop. Strip is 56 px high and full width, flush with the bottom of the visible area (portrait y 1224, 800 wide; landscape y 744, 1280 wide).
 - `_NET_WM_STRUT_PARTIAL` (and `_NET_WM_STRUT`) bottom strut, measured from the screen edge: 56 in portrait, 536 in landscape on the 1280x1280 root (480 below the panel + 56). Mapped only while `_NET_ACTIVE_WINDOW` (watched with PropertyNotify on the root) is a window that is neither the shell nor the dock, nor none; unmapped when the shell or nothing is active; a tap on the dock itself keeps the state. On every map it is painted at once and restacked on top (a remapped X window keeps its old stacking place; found by the test).
 - Buttons (thirds of the strip, 56 px targets, pressed state): Home raises the shell (`_NET_ACTIVE_WINDOW` client message to the window manager plus a plain restack so it also works without a WM); Keyboard sends the core `keyboard` toggle; Close app maps the active window's WM_CLASS (instance or class, case-insensitive) to an apps.json id through its `wm_class` and sends `close_app`, an unknown class is a silent no-op. Release must land on the same button as the press.
 - Rotation: the shell tells the dock its size; the dock derives the panel size from the aspect (800x1280 / 1280x800), not from the shell size, because a maximised shell shrinks by the dock's own strut while it is up (that would otherwise move the dock in a feedback loop).
 - If the dock's X connection cannot be opened the shell logs it and runs without a dock; if it fails later the dock is dropped, the shell keeps running.
