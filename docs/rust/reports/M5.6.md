# M5.6 Device and Settings screens
Status: done on the host (unit tests, 19 goldens, full-stack round trip through the real core); not yet on the tablet
Files changed: crates/walpad-hw/src/sysinfo.rs (new), crates/walpad-shell/src/{config,device_screen,settings_screen,app,app/tests,overlay,shell,lib}.rs, crates/walpad-shell/tests/{screens_snapshots,x}.rs, crates/walpad-shell/tests/golden/* (19 new), scripts/check.sh
What works now:
 - Device tab: brightness slider; rotation list (Auto, Portrait, Landscape, Portrait flipped, Landscape flipped, current one ticked from status); "Dim after" and "Screen off after" choices (30 s ... 10 min, Never) and the cover toggle, all written through `set_setting` and read back from devd.json after the core's reply; battery (level with its source, state, voltage, temperature, low and critical thresholds read-only); touch (status, calibration "Not available yet"); hardware list where every unavailable item says so: accelerometer, audio "Unverified", Bluetooth/SD card "Unavailable", USB OTG "Not tested", camera "Unsupported". The battery estimate is labelled "(estimated from voltage)" in the warning colour. Offline everything reads "Unknown".
 - Settings tab: category list and subpages with a Back button (leaving Settings forgets the open page): Display (shortcut to the Device tab), Input (volume gestures from keys.json, read-only), Power (button behaviour, timeouts, thresholds), Network diagnostics (wpa state, SSID, IP, signal, gateway, DNS), Security (SSH listening and authorised key count; telnet shown as "USB only" or in red "Open on the network"), System (WalPad OS version, Alpine, kernel, architecture, storage, memory, uptime), Clock (24-hour toggle, applied at once), Maintenance (View logs, Restart shell, Restart tablet, Shut down), About.
 - Logs: last 200 lines of walpad-core.log, secrets masked (psk=, password, secret, token, passphrase and any long hex key).
 - Restart tablet / Shut down use a two-step dialog: the first confirm tap only arms the button ("Tap again to shut down"), the second within 3 s sends power with confirmed:true; the arming expires and the label reverts; nothing is sent while the core is down.
 - walpad-hw::sysinfo: kernel/alpine release, meminfo, disk usage, listening TCP sockets (little-endian /proc/net/tcp), default gateway, DNS, authorised key count, log tail + redaction; all through the Root prefix and all optional.
 - The shell re-reads devd.json / shell.json and the system facts when Device or Settings opens, after each setting reply, and once a minute while one of them is showing.
Checks run: scripts/check.sh -> ALL CHECKS PASSED. 61 shell unit tests (device commands, setting replies and errors, offline inertness, settings navigation and Back, clock toggle, restart shell, two-step power with expiry), 15 hw tests incl. redaction, 19 goldens (device portrait/landscape/locked+custom/offline, settings list portrait/landscape, 9 subpages, telnet-open warning, 3 power dialogs) inspected by eye, and a full-stack test: tap "30 s" on the Device tab -> the core writes devd.json -> the shell reads it back and moves the highlight (3/3).
Bugs/fixes along the way: the four X tests share one binary and ran in parallel on display numbers that could collide (flaky failure in 1 of 5 runs); every test now takes a unique display number from a counter. check.sh's secrets grep now exempts exactly the two files that contain deliberate redaction-test strings.
Measurements: walpad-shell 1,335,400 bytes (release, stripped, static aarch64).
Device checks pending: none yet (shell still not selectable until M5.9).
Deviations from plan: the Device tab lists rotation as five rows (a segmented control cannot fit "Landscape flipped"); "Dim after" offers 15 s/30 s/1 min/90 s/Never (the plan lists only the screen-off options).
Known limits: Telnet scope is read from /proc/net/tcp (IPv4 only); the Logs page shows the core log only; Restart shell kills the shell for the supervisor to restart.
